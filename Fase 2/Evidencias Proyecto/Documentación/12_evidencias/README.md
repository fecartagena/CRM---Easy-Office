# Evidencias

Respaldo de las sesiones con Easy Office y de las decisiones del proyecto.

| Contenido | Formato | Condición |
|---|---|---|
| Transcripciones de las sesiones de levantamiento (`T1`, `T2`) | .md / .pdf | Anonimizadas antes de versionarse |
| Actas firmadas o confirmadas por correo | .pdf | Sin datos personales de clientes |
| Grabaciones de reuniones | Enlace a carpeta de acceso restringido | No se versionan en el repositorio |
| Capturas de demostraciones de cierre de sprint | .png | Solo con datos sintéticos |

Este repositorio es público: ningún archivo de esta carpeta puede contener datos
personales reales de clientes de Easy Office.
