## Propósito

Demostrar la cadena completa del proyecto:

**Requerimiento → Historia de usuario → Desarrollo → Prueba → Evidencia**

A la fecha de esta versión solo están poblados los tres primeros niveles. Las columnas de
issue, commit, prueba y evidencia se completan a medida que avanza el desarrollo.
De este modo la matriz registra el avance real del proyecto sprint a sprint.

## Cómo se mantiene

1. Al crear una historia en GitHub Projects, se registra el número de issue en la
   columna correspondiente.
2. Los commits y Pull Requests referencian el issue, de modo que la columna
   *Commit / PR* se puede completar desde el historial del repositorio.
3. Al escribir la prueba que cubre la historia, se anota su identificador.
4. Al cerrar la historia, la columna *Evidencia* apunta al artefacto que la
   demuestra: captura, resultado de prueba, documento o incremento ejecutable.

El estado de un requerimiento avanza así:
**Especificado → En desarrollo → Implementado → Verificado → Validado con la
contraparte.**
