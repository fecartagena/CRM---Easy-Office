# CRM---Easy-Office
Desarrollo de una plataforma web para Easy Office que centralice la gestión de clientes y trámites, automatice la generación de documentos y permita integrar procesos de firma electrónica avanzada. La solución busca reducir tiempos, disminuir errores manuales y facilitar que ciertos servicios puedan gestionarse en línea de forma rápida y segura.
